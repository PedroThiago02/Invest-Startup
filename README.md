# Invest Startup 🚀

Um site institucional moderno e responsivo para apresentar a proposta da **Invest Equilíbrio** — uma startup voltada para investimentos acessíveis e inteligentes.  
O projeto foi construído com HTML puro e TailwindCSS, focando em simplicidade, usabilidade e estética.

---

## 🌐 Acesse o Projeto

> [Invest Equilíbrio Financeiro](https://pedrothiago02.github.io/Invest-Startup/)

---

## 📁 Estrutura do Projeto

```
Invest-Startup/
├── assets/
│   ├── css/           → Estilos personalizados
│   ├── img/           → Imagens do projeto
│   └── js/            → Scripts JavaScript (futuramente)
├── pages/             → Outras páginas (Planos, Contato, etc.)
├── index.html         → Página inicial
├── README.md
└── .gitignore
```

---

## ✨ Tecnologias Utilizadas

- HTML5
- [TailwindCSS](https://tailwindcss.com/)
- Design responsivo (mobile-first)

---

## 🔧 Funcionalidades

- Página inicial com apresentação da startup
- Páginas informativas sobre planos, funcionamento, benefícios, etc.
- Página de login e cadastro com efeito de flip (cartão 3D)
- Design otimizado para dispositivos móveis

---

## 🚀 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/PedroThiago02/Invest-Startup.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd Invest-Startup
   ```

3. Abra o arquivo `index.html` em seu navegador (clique duplo ou use uma extensão de live server).
